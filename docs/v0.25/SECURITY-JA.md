# v0.25 外部流動性読取りの信頼境界

外部板アダプターには秘密鍵、財布解除、署名、任意RPC、注文、出金APIがありません。共有ノードは静的な画面と限定モジュールを配信するだけで、サーバー側の任意URL proxyを新設しません。ブラウザ/CLIが、利用者が明示した接続先へ市場IDを照会します。

認証済みの資産情報・独立したネットワークID・コンセンサス・実際の約定・実行費用を証明するものではありません。名前が同じ資産、wrapped/native、別ネットワーク、取引所内残高と外部ウォレットを自動的に同一視しません。

HTTPはcredentials omit、redirect error、no-store。root originに限定し、外部HTTPSは完全一致で許可、本文サイズ・タイムアウト・同時要求数を制限します。gRPC-Webはbinary unaryの1メッセージと最後のstatus 0を必須とし、重複・切断・圧縮・曖昧な応答を拒否します。JSONは既存の重複キー拒否・数値表記保持パーサーを使います。

数量は整数、価格は有理数として扱います。端数丸めは参考モデルであり、実際のmatching engineの精算と同一とは保証しません。Injectiveの基準taker rateが分かっても、atomic order倍率や口座別条件は未検証です。HyperCoreの実手数料は未取得です。最低受取の仮計算は署名済み保護条件ではありません。

入力・接続先変更、停止、ページ終了、期限切れで観測を無効にします。遅い古い応答が新しい結果へ上書きできないことを検査します。見積りの保存や再読込から実行可否を昇格する機能はありません。

既存ウォレット・relay・contractsの権限は今回変更していません。過去の主口座・AI停止・バックアップ・オンチェーン補助鍵の制約は維持します。v0.21共同承認WIPは未統合として別保管。正式環境、全体ビルド、実ブラウザHTTP/CSP、公開API・テストネット、独立監査が未完了です。
