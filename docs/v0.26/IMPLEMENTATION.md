# v0.26 実装記録

## 目的

版番号やZIPの名前だけを基点にせず、Git commitを開発と試験の基点にする。
元のv0.25を保全し、並行作業で既存機能を落とさず統合できるようにする。

## 実装

- `app/ci.mjs`: 5群の並行ソース試験。最大4指定・既定3同時。制限付き子環境、
  排他的ログ作成、時間・ログ上限、中止処理、TAP実行数とソース前後hashの検査。
- `.github/workflows/parallel-source-ci.yml`: 5群のmatrix、最大3同時、読取り権限、
  credentials非保持、全matrix結果をまとめた必須化可能なgate。自動公開・mergeなし。
- `dev/workspace.mjs`: 作業ブランチとworktree作成、担当パスの検査。既存作業のresetなし。
- `dev/source-hygiene.mjs`: 最新ファイルだけでなく、mainから到達する履歴のblobと全treeを
  検査。発見した値は出力せずパスとルールだけ記録。ヒューリスティック検査であり監査ではない。
- `app/lib/project-metadata.mjs`: RELEASEとpackage versionを区別、Node/pnpmの固定値を照合。
  v0.25がdoctorで0.24と表示される事象を入力ZIPで再現して修正。
- `node/external/injective-orders.mjs`: 観測した市場条件に対する未署名の注文・取消しメッセージ。
  実送信なし。部分約定・取消し待ち・不明の状態でも残余予約の自動解放なし。

## 制限

GitHub connectorに公開されている操作は読み取りのみ。ローカルghと認証も未配置。
このためリポジトリ作成・push・GitHub CIの実行・保護設定・PR作成は未実行。
CIコードは実装しローカルの制御フローを試験したが、remoteの成功として扱わない。
独立した複数AIを起動したものではなく、一人のアシスタントが分離した作業領域を使い、
実際の試験プロセスを並行実行した。

外部注文は未署名の準備まで。口座・市場・実費用の認証、所有者署名、永続注文履歴、
公開取引所での注文・取消し・出金は未実装。
全体依存は取得できず、正式ビルドや本番承認を新しく通したものではない。
OSの隔離・複数端末の秘密鍵保護・独立監査もこの変更だけでは成立しない。
