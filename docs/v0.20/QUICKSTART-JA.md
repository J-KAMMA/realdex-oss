# RealDEX v0.20 — Cosmosの制限付き代理送金

## 目的
EVMスマートアカウントを保持し、Cosmos SDKのネイティブauthzを追加した開発版です。Cosmos側に別のコントラクト口座を作る方式ではなく、所有者の口座に資産を残してSendAuthorizationを付与します。未監査・自設ローカルチェーン専用です。実資産のある鍵は使用しないでください。

## 更新と起動
旧プロセスを正常終了し、暗号化バックアップ・設定を別途保全してください。ZIPを別フォルダーに展開し、app/が見える場所で実行します。

```sh
node app/cli.mjs start
```

通常起動にnpm installやsimdは不要です。ターミナルに表示される所有者専用URLを同じPCで開きます。URLの#key、保管庫パスワード、秘密鍵をAIや共有ノードへ渡さないでください。保存先の自動移行は行いません。

## 必要な設定
既存のCosmos接続設定を利用します。chainIdはrealdex-local-で始まる自設チェーン、通常のsecp256k1 BaseAccount、2〜4組の127.0.0.1上のCometBFT RPC/SDK REST、独立に確認したcheckpointが必要です。URL数は独立ノード数ではありません。localhostが本番ノードを中継していないことも確認してください。

新規許可では所有者・代理人・受取先の口座がチェーン上に存在する必要があります。代理人には、所有者の資産とは別に送信手数料用残高を用意します。

## 画面操作
「Cosmos · チェーン側で制限する代理送金」を開きます。

許可作成では所有者口座を選択し、代理人アドレス、許可する受取先1口座、累計数量の最小単位整数、有効期限（端末のタイムゾーン、作成時から最大7日）、手数料・ガス上限を指定します。準備は未署名のシミュレーションです。承認画面にはGRANTから始まる全条件の確認文が表示されます。全文を再入力し、送信を明示的に選んで承認します。送信チェックの初期値はOFFです。

代理送金では代理人口座を選び、資金を持つ所有者、許可された受取先、送金数量を指定します。所有者の資産が減り、代理人が手数料を負担します。今回は所有者UIから操作する経路です。AI MCPへ権限を自動接続してはいません。

取消しでは所有者口座・代理人を選び、REVOKE確認文を再入力します。取消しが収録されるまで権限は生きています。既存許可は上書きせず、取消し確認後に再付与します。再付与は新しい予算を意図的に与える操作です。

履歴で元の取引を再照合してください。許可・取消しの完了と送金の受取は別に表示します。「現在の許可を照合」は最新の残り枠を読む操作で、署名しません。

## バックアップと停止
新しいauthz履歴を保存した保管庫は旧版で開けません。旧バイナリで上書きしないでください。古いバックアップへ戻してもオンチェーンの消費枠は回復しませんが、ローカルの取引履歴は失われ得ます。未知の送信を自動再作成する手段に使わないでください。

PCのロック・AI停止はオンチェーンの許可取消しではありません。署名済み取引や、別の端末にある代理鍵はPCをロックしても使用可能です。取消取引・有効期限で止めます。

送信結果不明の口座は新規署名を保留します。自動再送・手数料引上げ・予約解除はありません。結果不明の許可作成がある場合、その保管庫からの取消しも新規署名として保留されます。独立して確認したノードや別の所有者クライアントでの復旧検討が必要です。保留中のデータを削除して再送しないでください。

## 再現デモ
別配布のRealDEX-Cosmos-Simd-Test-Toolchain-2026-09-06.zipを照合し、simd-linux-amd64を展開します。Linux x86-64のみの試験用開発ビルドです。

ZIP SHA-256: 7705b99457444bebaca99e056f6ba2d6e03765e4071236274fd9a5ad9395789d

実行ファイルSHA-256: 8bd38fcc35329b331fb73caabdb0287f4cfde62f6593c36fd32e27664619f838

```sh
chmod 700 /absolute/path/to/simd-linux-amd64
export REALDEX_SIMD_BINARY=/absolute/path/to/simd-linux-amd64
node integration/cosmos/authz-demo.mjs
node --test --test-concurrency=1 integration/cosmos/Authz.test.mjs
```

デモは使い捨てのチェーン・鍵・保管庫を生成して終了時に削除します。既存の利用者用保管庫は読みません。テスト用の初期残高は無価値です。

```sh
node app/verify.mjs --cosmos --output acceptance-new
```

--cosmosは従来の送金と新しいauthz実行試験の両方を要求します。未実行を合格にはしません。全体確認は--fullで実行できますが、正式コンパイラ・完全な依存・実ブラウザ・監査などが未達なら本番判定はfalseです。
