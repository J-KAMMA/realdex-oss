# v0.17の信頼境界

## 変更した範囲

Cosmosオンライン送金は既存のowner側NonEvmController、保管庫、ロック世代、承認待ち要求、sequence予約を利用します。AI・MCP・外部アプリ・共有ノードへ署名権限を追加しません。秘密鍵は署名時のみ使用し、Simulateには公開鍵とゼロ署名を渡します。RPC資格情報の登録はこのCosmos APIにはありません。cookieやAPI鍵をURLへ埋め込む形式も拒否します。

## 保護すること

未解決の署名を別sequenceや期限で自動置換しません。現在の保管庫で同じ口座・ネットワークに未解決取引があれば、オフライン経路からの新規署名も止めます。署名履歴とsequence予約を保存し、さらに送信開始前の不明状態を保存してから署名データを外部へ出します。保存失敗、設定変更、途中ロックでは進行中の古い要求を失効させます。遠隔が受理した後のロックは取引取消しではありません。遅い成功返信を新セッションへ書き戻さず、履歴を再照合します。

固定checkpoint、chain ID、BaseAccount、公開鍵、denom、数量、fee、gas、accountNumber、sequence、timeoutHeightは署名前に確認し直します。送信先の所有者確認、設定fingerprint、期限の再検査は初回送信時にも行います。設定、準備済み要求、保存済み取引を同じ内容へ結び付けます。

## 保護できていないこと

1. 同じPC全体の侵害、任意シェルを持つAI、OS管理者、保管庫とコードの同時改変を隔離するものではありません。
2. RPC同士の一致やMerkle包含は、ブロックヘッダー、validator投票、application stateの正しさを独立に証明しません。ブリッジでの資金解放に使いません。
3. UIのdenom桁数・記号・費用単位は所有者の設定です。信頼できるトークン情報サービスではありません。
4. 未解決記録、低すぎるfeeのCheckTx拒否、失効した署名を安全に解放する運用UIは未実装です。可用性より二重支払いの回避を優先し、保留を維持します。
5. 古いバックアップ、別保管庫、別端末、別アプリにまたがる署名予約は強制できません。復元を取消しと見なさないでください。
6. vesting口座、multisig、Ethermint/Injective型口座、IBC、authz、feegrant、unordered transaction、任意メッセージ、swap、bridgeは対象外です。
7. 試験用simdは固定した公式開発ビルドです。本番採用・安定版の動作保証ではありません。公開テストネット、Cosmos Hub、各SDK派生チェーンは未試験です。

## 検証の区別

新規単体試験では合成HTTP状態とOpenSSLによる署名検査、Merkle木の561内部ケースなどを使用します。simd試験は一つのvalidatorによる実行・bank module・fee・sequence・ブロック収録を使いますが、HTTP入口は同じノードへ向かう中継であり独立ノードではありません。通信断や悪意の返信は中継の故障注入です。

オフライン画面試験はHTTP・CSP・暗号処理の結合検証ではありません。既存Bitcoin Core、Anvil、LiteSVM、固定nightly AMMの試験は別区分で再実行し、Cosmosや正式コンパイラの合格として流用しません。実行結果の詳細は同梱の検証記録を参照してください。
