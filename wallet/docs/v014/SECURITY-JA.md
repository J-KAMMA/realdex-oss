# RealDEX v0.14 — 安全性と非対応範囲

## 本番判定

未監査の開発版です。productionReady=false。実資産・本番鍵を使用しないでください。今回の追加は所有者専用です。AI/MCP、接続dapp、共有ノードへ新しい署名権限は追加していません。

## 署名と実行の区別

SPLは実際のLiteSVM Token Programで署名と残高変化を検査しました。ただしRPCのスロット・finality・genesis等は合成で、独立した2ノードでも公開validatorでもありません。

Bitcoin/Cosmos/Stellar/Aptosは実際の暗号署名と標準取引形式を生成・検証しますが、それぞれのチェーンで実行していません。残高、UTXOの存在・未使用性、sequence、口座番号、口座作成・reserve、手数料の適正値は認証しません。正しい署名であっても取引が有効・成立すると保証できません。

BitcoinとSolanaは独自のチェーンIDを署名バイトへ付加していません。ローカルのアドレス表記や設定名だけで本番鍵の使用を安全に制限できるとは限りません。署名済み要求を試験用以外へ搬出しないでください。Cosmos/ Stellar/ Aptosの署名にネットワーク識別が含まれていても、接続先の信頼性や名前の真正性は別です。

## 保存・重複防止

署名と使用済みUTXO/sequenceを同じ暗号化履歴へ保存し、保存エラーなら結果を返しません。出力・ネットワーク送信は保存後です。同じ支払いキーと同じ内容は既存結果へ戻り、内容変更は拒否します。ただし別キーを使った同じ請求を自動同定する機能ではありません。

ローカル予約はオンチェーンの制限ではなく、古いバックアップ、別端末や同じ鍵を使う他ウォレットには適用できません。署名済み取引の取消し・fee bump・安全な予約解除・履歴アーカイブは未実装です。非EVM履歴の上限128件は維持しています。履歴を削除して制限を迂回しないでください。

## SPLの制約

古いToken ProgramのTransferCheckedだけです。明示した送受双方の既存トークン口座と所有者を照合します。Token-2022、追加拡張、wrapped SOL、凍結、delegate、close authorityは拒否します。ATA自動作成、プログラムアップグレードの独立証明、トークン価格・価値・発行者監査はありません。RPCが共謀して嘘を返す脅威を結果一致だけでは防げません。

送信後の取引の確定を、単なるRPC受付とは分けます。状態が消える・不一致になる場合は成功観測を撤回しますが、それ自体が未送金の証明ではありません。

## PC・認証

保管庫は既存のscrypt/AES-GCM方式です。OSキーストア・ハードウェア署名器・完全なメモリ消去保証はありません。同じPCで自由にシェル・ファイル・画面を操作できるAIやマルウェアは、限定MCPだけを与えた場合とは異なる脅威です。所有者専用URL、パスワード、鍵、署名済みファイルを渡さないでください。

停止ハンドラーの登録を起動URLの表示より前へ移し、起動直後の停止でwriter lockが残る競合を修正しました。SIGKILLや実電源断でも常に安全な自動復旧ができるという主張ではありません。

## 既存未達を維持

React全体ビルド、固定0.8.24コンパイラ、公開テストネット、通常ブラウザのHTTP/CSP、Windows・OS鍵保護、独立監査は今回の完成条件に未達です。ICP認証済み決済、Bitcoin/Cosmos等のネットワーク送信、非EVMのDEX・bridge、AIの非EVM自動送金、全時価総額100位資産対応は未完成です。
