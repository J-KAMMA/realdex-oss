ノードが教えたRPCへは接続しません。EIP-1898非対応、別チェーン、情報不一致、古いブロックでは停止します。RPCへは対象アドレスが伝わります。

02 / REQUEST

比較する交換を固定する

シンボルや桁数を推測しません。入力額は最小単位です（例：小数6桁のトークンなら1枚 = 1000000）。最大32組のFactory×料率を照合します。

指定時のみ、ボタン操作で残高・既存承認・eth_call・ガス見積りを確認できます。承認が不足していれば止まり、承認取引は作成しません。受取先も同じ公開アドレスです。

条件を入力してください。自動接続は行いません。
